# Contributing to XYN (release candidate)

Please propose changes to the canonical `personas/` sources and rebuild adapters via `python tools/build_adapters.py`. Do not hand-edit generated adapters without regenerating them. Run unit tests and `--check`; explain which Q decisions and role contracts the change impacts. Never include model keys, real private SOUL files, specialist memory, screenshots of private messages or machine-specific paths. This RC has no approved open-source license yet, so contributions should not be solicited publicly until legal terms are selected.
