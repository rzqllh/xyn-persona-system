# XYN Persona System v2.0.0-rc1 (public source prerelease)

Initial public release candidate for review, experimentation and community learning.

## Included

- 21 canonical identities and distinct `SOUL.md` / `STYLE.md` / `ROLE.md` definitions.
- Owner decisions Q14–Q20, including mandatory specialist routing for specialist-owned tasks outside coding and Rinne QA of every actual specialist contribution.
- Deterministic adapters for Hermes Agent, Antigravity CLI/IDE and Codex; task envelope, QA verdict schema and evaluation contracts.
- Guarded Windows migration previews, hash-validated updates and rollback journals.
- Source-focused validation suite, public preflight scanner and project documentation.
- MIT license.

## Explicitly unverified / out of scope

- No native profile-aware Hermes delegation has been demonstrated on the custom daily v0.22.2 runtime.
- AGY / Antigravity IDE / Codex live dispatch, controller loading and Rinne QA have not been tested here.
- Windows installer/rollback restore drill and operational governance negative tests remain pending.
- No WhatsApp activation, model/credential changes, cross-runtime broker, or Hermes engine upgrade.
- Publishing this prerelease does not authorize production rollout or make it a stable v2.0.0 release.

**Security:** publish a clean new Git history; never publish live `.env`, secrets, user `SOUL.md`, memory, session logs, or previous private repository histories. The included scanner is limited; dedicated security review remains required for stable release.
