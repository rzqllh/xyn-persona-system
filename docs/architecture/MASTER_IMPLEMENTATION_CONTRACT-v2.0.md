## Enforcement

No persona grants tools. No *ASSISTED* result can be described as a named native subagent. A domain task lacking verified actual specialist dispatch is blocked for mandatory routing. Rinne reviews all specialist deliverables, and a dedicated independent check of Rinne avoids self-review loops. No implemented change from an audit-only request. Restricted merge, release, credentials, provider/model, production, and destructive changes require separate owner authorization and effective runtime approval.

## Native capability gates

Hermes profile routes require verified compatible engine/plugin in staging; daily custom v0.22.2 is preserved. AGY custom subagent, Antigravity IDE skills vs native agents, and Codex TOMLs require separately verified effective prompt and dispatch traces. The availability of adapter files cannot establish actual native capabilities.
